# Prism Core — HTML5版

Python / Pygame版をJavaScriptとCanvas 2Dで移植。外部ライブラリ、CDN、ビルド作業は不要です。

## 起動

Windowsでは `start-server.cmd` をダブルクリックし、ブラウザで http://127.0.0.1:8080 を開きます（Pythonが必要）。または、このフォルダで次のコマンドを実行します。

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

`index.html` を直接開くこともできますが、音声とタブ保存の挙動を揃えるためHTTPでの起動を推奨します。
スマホで確認するときは同一LAN上のPCで `python -m http.server 8080 --bind 0.0.0.0` を実行し、スマホから `http://PCのLAN内IP:8080` にアクセスしてください。必要に応じてOSのファイアウォール設定を確認してください。

## 操作

- スマホ横持ち：左スティックで移動、右スティックを倒して照準・連射。各スティックは別々の指で同時操作できます。
- PC：WASD / 矢印キーで移動、マウス左ボタン長押しで射撃。
- 右上の「Ⅱ」、Space、Esc、Pで一時停止。「ⓘ」で詳細ステータス。
- 右上のミニマップをタップして拡大（一時停止します）。
- スマホを縦にする、タブを切り替える、ウィンドウから離れると自動で一時停止。再開は明示操作です。
- ホームで日英切替、ミュート、対応ブラウザでの全画面表示。一時停止画面で効果音とBGM音量を調整。

## 進行と戦績

1〜9階は黄色いスイッチをすべて踏むと出口が開きます。次の階でHPは全回復。
10階はボスを倒してから出口へ入るとクリアです。1〜9階をすべて全滅させ、プレイ時間300秒以内に10階へ到達すると真ボスが出現します。
真ボスは4段階の攻撃を持ち、HP50%で出現するバリア装置を破壊すると最終段階に進みます。

戦績・図鑑の撃破数・ボストロフィーは **sessionStorage** に保存します。
同じタブ内の再挑戦、タイトルへの移動、再読み込みでは保持し、タブを閉じて新しく開くとリセットします。
ブラウザの「閉じたタブを復元」やセッション復元ではブラウザがsessionStorageを復元する場合があります。ストレージが無効の場合はページのメモリだけで保持します。
元の `data/*.json` は読み込まず、書き換えません。

## 元の実装との対応

- 元コードのHP・攻撃力・速度・射撃間隔、敵6種類とボス2種類、フロア別の出現確率を基準に移植。
- 100×100タイル、20pxタイルのダンジョン。部屋配置の縮小リトライ、L字通路、スイッチ、探索マップ。
- 追尾弾・爆発弾、トークンによる強化、経験値とレベル、回復波動、無敵波動、真ボスのバリア装置。
- 60Hz固定ステップで更新し、画面描画のリフレッシュレートからゲーム速度を分離。
- スマホ向けに表示範囲とHUDを再設計。内部の図形をCanvasで描き直し、敵色を読みやすく調整。
- 意図的な改善：ポーズ時間をクリアタイムから除外、レベル10で確実に上限停止、死亡を同フレームの階層移動より優先。
- READMEの古い説明ではなく現行Python実装を採用（初期HP200・ATK20、Spaceはポーズ、プレイヤー用バリア操作なし、ハートトークンは回復、ヘキサゴンの接触ダメージは現行実装にないため追加なし）。
- 音源は元素材のコピー。効果音を22.05kHz・16bit・モノラルPCMに変換。必要になった音だけ読み込みます。
- HTTP配信時の音声は、最初のタップでWeb Audioを有効化して再生します。ポーズ解除時にも再有効化し、再挑戦や階層移動では古い効果音を停止します。ファイルを直接開く場合はHTMLAudioに切り替えます。
- BGMは軽量なOGGを優先し、OGG非対応または読み込み・デコード失敗時は互換用WAVに切り替えます。互換用ファイルは元BGMから22.05kHz・16bit・モノラルPCMで生成しました。通常はWAVをダウンロードしません。

## ファイル

- `core.js`：ブラウザに依存しないゲームロジック
- `app.js`：描画、入力、画面遷移、音、戦績保存
- `audio.js`：タップ時の音声有効化、音声読み込み・再生管理
- `style.css` / `index.html`：スマホ向けUI
- `assets/sounds/`：Web版専用の音素材
- `tests/core.test.cjs`：生成マップの到達可能性、階層進行、ボス・弾幕・成長・ポーズのテスト
- `tests/input.test.cjs`：左右同時操作、pointercancel、画面切替時の入力解除
- `tests/audio.test.cjs`：音声有効化、読み込み中のポーズ・画面遷移
- `tests/campaign.test.cjs`：移動・射撃入力による全10階の進行（通常／真ボスの両ルート）
- `tools/convert-audio.html`：BGMの互換用WAVを再生成する開発用ツール（外部ライブラリ不要）

```powershell
node --test tests/*.test.cjs
```

このフォルダを静的Webサーバーで配信できます。自動公開や外部サービスへのアップロードは行っていません。

## 確認済みの範囲

- Node.jsの自動テスト22件が成功。30シード×10階の到達可能性、ボスの攻撃段階、弾の分裂、成長、同時入力、音声の非同期処理を検証。
- 全10階の自動進行テストでは、位置の直接変更や階層スキップを使わず、移動・射撃入力からスイッチ起動、ワープ、ボス撃破、勝利まで確認。進行確認用にテスト内だけでHP・攻撃力を増やしており、通常の難易度・操作感を保証するテストではありません。
- ボス撃破と同じフレームに発生する爆発弾の破片も消去されること、再挑戦時に敗北音が止まること、BGMなしのフロアでも再開操作で音声が再有効化されることを回帰テストで確認。
- デスクトップのブラウザで起動、640×360 / 844×390の横持ちレイアウト、メニュー、図鑑、ポーズ、戦績の表示と再読み込み保持、新規タブでのリセットを確認。
- ブラウザの最終確認でコンソールの警告・エラーなし。
- 実際のiPhone / Androidでの操作感・音声・長時間の性能は未確認です。ブラウザで全10階を手動クリアする通しプレイも未実施です。
